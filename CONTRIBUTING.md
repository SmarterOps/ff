# Contributing

Thanks for helping improve `ff`! Bug reports, suggestions, and pull requests
are welcome.

## Reporting a bug

Open a GitHub issue with:

- The command you ran and the operating system/shell you used
- What happened and what you expected to happen
- Relevant error output

Do not include passwords, tokens, or other private information.

## Submitting a change

1. Fork the repository and create a branch for your change.
2. Keep the change focused and update the README when user-facing behavior
   changes.
3. Check Bash syntax:

   ```bash
   bash -n ff install.sh
   ```

4. Test the affected behavior manually in a temporary directory.
5. Open a pull request describing the change and how you verified it.

By contributing, you agree that your contributions are provided under the
project's [MIT License](./LICENSE).
